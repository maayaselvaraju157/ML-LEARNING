Level 3: Searching Algorithms
13. Linear Search
Linear search checks each element one by one until the target is found.
a = [10, 20, 30, 40]
target = 30
for i in range(len(a)):  
  if a[i] == target:      
  print("Found at index", i)    
    break
Output:
Found at index 2


Time complexity: \(O(n)\)
14. Binary Search
Binary search repeatedly divides a sorted list into halves to find the target.
a = [10, 20, 30, 40, 50]
target = 40low, high = 0, len(a) - 1while low <= high:   
 mid = (low + high) // 2   
 if a[mid] == target:     
   print("Found at index", mid)    
    break    elif a[mid] < target:   
     low = mid + 1    
else:      
  high = mid - 1
Output:
Found at index 3


Time complexity: \(O(\log n)\)
Level 4: Sorting Algorithms
15. Bubble Sort
Bubble sort compares adjacent elements and swaps them when they are in the wrong order.
a = [5, 3, 1, 4]
for i in range(len(a)):
    for j in range(len(a) - 1 - i):    
    if a[j] > a[j + 1]:        
    a[j], a[j + 1] = a[j + 1], a[j]
print(a)
Output:
[1, 3, 4, 5]


Time complexity: \(O(n^2)\) in the average and worst cases.
16. Selection Sort
Selection sort finds the smallest remaining element and places it in the correct position.
a = [4, 2, 5, 1]
for i in range(len(a)): 
   m = i   
 for j in range(i + 1, len(a)):     
   if a[j] < a[m]:       
     m = j    a[i], a[m] = a[m], a[i]print(a)
Output:
[1, 2, 4, 5]


Time complexity: \(O(n^2)\)
17. Insertion Sort
Insertion sort takes each element and inserts it into the correct position in the already-sorted part.
a = [5, 3, 4, 1]
for i in range(1, len(a)):  
  key = a[i]    j = i - 1    
while j >= 0 and a[j] > key:    
    a[j + 1] = a[j]        j -= 1    a[j + 1] = key
print(a)
Output:
[1, 3, 4, 5]


Time complexity: \(O(n^2)\) in the average and worst cases.
18. Merge Sort
Merge sort divides a list into smaller parts, sorts them, and merges them.
a = [5, 2, 4, 1]
a.sort()
print(a)
Output:
[1, 2, 4, 5]


Time complexity: \(O(n\log n)\)

Note: This short example uses Python's built-in sorting. The actual merge sort algorithm uses divide and merge steps.
19. Quick Sort
Quick sort selects a pivot, partitions the elements around it, and sorts the partitions.
a = [7, 3, 9, 2]
a.sort()
print(a)
Output:
[2, 3, 7, 9]


Time complexity: Average \(O(n\log n)\); worst case \(O(n^2)\).

25. Singly Linked List
Each node points to the next node only.

26. Doubly Linked List

54. Breadth-First Search (BFS)
BFS visits nearby nodes first and uses a queue.
from collections 
import dequegraph = {"A": ["B", "C"], "B": [], "C": []}
q = deque(["A"])
visited = set()
while q:  
  node = q.popleft()  
  if node not in visited:   
     print(node)        
visited.add(node)       
 q.extend(graph[node])
Output:
A
B
C


55. Depth-First Search (DFS)
DFS explores one path as far as possible before backtracking.

visited = set()def dfs(node): 
   if node in visited:      
  return   
 visited.add(node)
    print(node)   
 for nxt in graph[node]:
        dfs(nxt)dfs("A")
Output:
A
B
C


56. Dijkstra's Algorithm
Dijkstra finds shortest paths from a starting node in a graph with non-negative edge weights.
Example: Finding the shortest road distance between cities.

57. Topological Sorting
Topological sorting orders the nodes of a directed acyclic graph (DAG) so each prerequisite appears before its dependent task.
Example: Completing prerequisites before taking a course.

58. Minimum Spanning Tree
A minimum spanning tree connects all vertices of a connected, undirected, weighted graph with minimum total edge weight.
Algorithms: Kruskal's algorithm and Prim's algorithm.


Level 12: Dynamic Programming (DP)
59. Dynamic Programming
Dynamic programming solves problems by storing results of smaller subproblems to avoid repeated calculations.

60. Memoization
Memoization stores previously calculated results, usually using recursion.
memo = {}def fib(n):   
 if n <= 1:   
     return n   
 if n not in memo: 
       memo[n] = fib(n-1) + fib(n-2)    
return memo[n]
print(fib(6))
Output:
8


61. Tabulation
Tabulation solves subproblems iteratively and stores their answers in a table.
dp = [0, 1]
for i in range(2, 7):  
  dp.append(dp[i-1] + dp[i-2])
print(dp[6])
Output:
8

63. 0/1 Knapsack
Choose items with given weights and values without exceeding the available capacity. Each item can be selected at most once.
Example: Selecting valuable items that fit into a bag.

64. Longest Common Subsequence (LCS)
LCS finds the longest sequence common to two strings while preserving character order.
Example: "ABC" and "AC" have LCS "AC".


Level 13: Greedy Algorithms
65. Greedy Algorithm
A greedy algorithm chooses the best available option at each step, hoping to achieve the overall goal.

66. Activity Selection
Select the maximum number of non-overlapping activities, usually by choosing the activity that finishes earliest.

67. Coin Change — Greedy Approach
Choose the largest available coin that does not exceed the remaining amount.
Note: This does not give the optimal answer for every coin system.

68. Fractional Knapsack
Choose items by value-to-weight ratio. Unlike 0/1 knapsack, fractions of items are allowed.
Example: Taking part of a quantity of rice to maximize value within a weight limit.


Level 14: Backtracking
69. Backtracking
Backtracking tries a possible solution, then reverses a choice if it does not lead to a valid solution.

71. Subsets
Subsets are all possible selections of elements from a set, including the empty subset.
Example: For [1, 2], the subsets are [], [1], [2], and [1, 2].

72. N-Queens Problem
Place N queens on an N×N chessboard so that no two queens attack each other.

73. Sudoku Solver
Use backtracking to fill empty cells while obeying Sudoku rules.


Level 15: Advanced Algorithms
74. Divide and Conquer
Divide a problem into smaller parts, solve them, and combine their results.
Examples: Merge sort and quick sort.

76. Greedy vs Dynamic Programming
Greedy makes a locally best choice at each step. Dynamic programming compares or combines solutions to smaller subproblems.

77. Union-Find (Disjoint Set Union)
Union-Find tracks groups of connected elements and supports merging groups and checking whether elements belong to the same group.
Example: Checking whether two computers belong to the same connected network.

78. Segment Tree
A segment tree supports efficient range queries and updates on an array.
Example: Finding the sum of elements between two indices after values change.

79. Fenwick Tree (Binary Indexed Tree)
A Fenwick tree supports efficient prefix-sum queries and updates.
Example: Calculating cumulative totals when individual values change.

80. KMP String Matching
The Knuth–Morris–Pratt algorithm searches for a pattern in a string without repeatedly checking the same characters.
Example: Finding "abc" inside "xxabcxx"

These patterns help you recognize which technique to use in coding interviews.
